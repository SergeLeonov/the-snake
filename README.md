# the-snake

Игра "Змейка"

## Обзор

Цель проекта — "Каждый программист хоть раз в своей жизни должен написать игру "Змейка"(с)
Почувствуйте себя хищником в естественной среде обитания, охотьтесь на беззащитную флору, растите
и становитесь сильнее. Кроме того, Вы получите в распоряжение технологию будущего, позволяющую Вам
атаковать свою жертву с неестественных для Вашего вида сторон! Но будьте осторожны, ведь с великой 
длиной приходит и великая опасность!

## Возможности

1) Управление с помощью клавиш управления курсором;
2) Изменение уровня сложности (SPEED);
3) Возможность проходить сквозь стены;
4) Случайная генерация яблока на поле;
5) Самоукус — поражение;
6) Игра автоматически перезапускается в случае поражения;
7) Провести часок времени в ностальгии :)
